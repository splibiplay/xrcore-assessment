# Asset Store Legal and Branding Checklist (Assessment)

Checklist de cumplimiento legal y de marca para la publicacion de `xrcore-assessment`.

## 1) Naming y marca

- [ ] Nombre comercial coherente con XRCore ecosystem.
- [ ] No se usan marcas de terceros de forma indebida en titulo o descripcion.
- [ ] Mensajes de marketing alineados con capacidades reales del modulo.

## 2) Propiedad intelectual

- [ ] Todo el contenido incluido es propio o tiene licencia valida.
- [ ] Recursos de terceros tienen atribucion/licencia documentada.
- [ ] No se incluye contenido con restricciones incompatibles con Asset Store.

## 3) Licencias y avisos

- [ ] Archivo de licencia del repositorio verificado.
- [ ] Avisos de terceros actualizados si aplica.
- [ ] Documentacion de uso de dependencias externas revisada.

## 4) Cumplimiento de publicacion

- [ ] Descripcion del paquete sin claims no verificables.
- [ ] Capturas y media reflejan el estado actual del producto.
- [ ] Versionado y changelog consistentes con el paquete enviado.
- [ ] Politica de soporte y contacto visibles.

## 5) Coherencia con politica GitHub docs-only

- [ ] README explica claramente que GitHub se usa para documentacion.
- [ ] Distribucion de runtime indicada como canal Unity/Asset Store.
- [ ] Enlaces de documentacion y ecosistema XRCore verificados.
