Evaluation layer for measurable XR training outcomes and certification workflows.

## GitHub policy

This repository is maintained as **documentation + release guidance**.
Runtime package delivery is handled through Unity distribution.

## Published foundation (Unity Asset Store)

Install XRCore foundation first:

- [XRCore - Event-Driven AI Framework for Unity XR](https://assetstore.unity.com/packages/tools/ai-ml-integration/xrcore-event-driven-ai-framework-for-unity-xr-366852)

## Value in 2 Minutes

1. Install SDK + Toolkit + Assessment.
2. Run training path `Look -> Grab -> Place`.
3. Trigger final evaluation.
4. Export score and validate pass/fail.

## What this module adds

- weighted scoring rules
- mandatory step enforcement
- critical failure handling
- report export workflows (JSON/CSV)
- runtime diagnostics for QA
