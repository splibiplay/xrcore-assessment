The enterprise evaluation layer for measurable XR training outcomes.

## Published foundation (Unity Asset Store)

Install the core SDK from Unity first, then add this module via Git URL:

- [XRCore – Event-Driven AI Framework for Unity XR](https://assetstore.unity.com/packages/tools/ai-ml-integration/xrcore-event-driven-ai-framework-for-unity-xr-366852)

## Value in 2 Minutes

1. Install SDK + Toolkit + Assessment.
2. Run the demo path `Look -> Grab -> Place`.
3. Trigger final evaluation.
4. Export assessment report and validate pass/fail.

## What It Adds

Assessment transforms guided execution into measurable performance:
- weighted scoring rules
- mandatory step enforcement
- critical failure handling
- JSON/CSV report export
- runtime diagnostics for QA
